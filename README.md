# 🎲 Yatzy Royale

A premium, highly interactive, and visually stunning 2-player client-side **Yatzy** scoresheet and virtual roller web application. Designed with modern cyberpunk/glassmorphic aesthetics, fluid 3D CSS dice transforms, Web Audio API synthesized retro sound effects, real-time score calculation engine, and a victory confetti engine.

🏆 **Trademark-Safe:** Fully rebranded to prevent conflict.
🧪 **Tested:** 100% automated validation with a visual cyberpunk testing dashboard.

---

## ✨ Features

- **Double Entry Modes**: Seamlessly toggle between **Virtual Roller** (with 3D physics animations, hold buttons, and roll limiters) and **Manual Entry** (touch targets for real-life play).
- **Automated Calculations**: Instantly updates subtotals, standard +35 point bonus (for scoring 63+ in the upper section), lower totals, Yatzy bonuses, and grand totals.
- **Accidental Click Protection**: Standard glassmorphic confirmation modal ensures players never accidentally log an incorrect score.
- **Joker / Subsequent Yatzy Rules**: Fully tracks subsequent Yatzys with dynamic visual +100 bonus stars and auto-wild joker calculations.
- **Pure Native Technology Stack**: Pure HTML5 structure, Vanilla CSS3 styling, and client-side JavaScript. Zero server dependencies, database requirements, or heavy build setups.

---

## 🚀 Getting Started

Simply open `index.html` directly in any modern web browser to play!

Alternatively, host it using any static provider such as **GitHub Pages**, Vercel, Netlify, or your own custom domain.

## 🧪 Visual Test Dashboard

The scoring computation logic is supported by a bespoke unit-testing dashboard validating 22 edge cases, type conversions, and defensive calculations.

To run the test runner:
1. Open the `/tests/tests.html` file in your browser.
2. The dashboard will automatically execute all specs and play a confirmation victory tune.
